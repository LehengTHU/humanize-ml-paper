%% tables.tex -- table library in the house style. Copy ONE float at a time
%% into a chapter; do not \input this whole file into a paper (labels repeat
%% the template names). Preview all samples with templates/tables_preview.tex.
%% Needs templates/preamble.tex (\pend, \ablation, \shrinktofit, oursrow,
%% oursrowblue, qualityrowcolor, costrowcolor, colours + and -).
%% Rules (references/figures_tables.md section 7): table* for the main table
%% even in one-column venues; caption ABOVE; \label after the tabular;
%% negative \vspace at the end; booktabs + a "|" after the row labels; width
%% only by scaling (never \small); bold header row; bold best (ties both bold);
%% \midrule\midrule between model scales; \arraystretch INSIDE the float.
%% Arrows: write $\uparrow$/$\downarrow$ [fix]: a typed Unicode arrow, common
%% in practice, vanishes under XeLaTeX with Times.
%% Width: house practice writes \resizebox{w\linewidth}{!}{...}. That also
%% enlarges a narrow table (its text then prints larger than body text), so
%% these samples use \shrinktofit{w\linewidth}{...} (preamble B8), which
%% scales only when the tabular is wider than w.
%% No results yet: keep the full row/column structure and fill cells with
%% \pend (renders "--"); never type made-up numbers [some].
%% Stacking: the negative end \vspace assumes TEXT follows the float. Two
%% floats stacked on one page overlap, so the samples below are separated by
%% \clearpage (harness only; do not copy those lines into a paper).
%%
%% WHICH MAIN TABLE (references/figures_tables.md section 7, "Main-table variants"):
%%   T1  scale-grouped, one baseline family, one metric      [some]
%%   T2  many baselines per backbone, one metric, Avg column [some]
%%   T4  quality + cost as a co-claim                         [some]
%% "(Ours)" appears only in baseline-heavy tables (T2); T1 and T4 name the
%% method alone and rely on shading.
